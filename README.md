# NotSoSimpleCalculator

A simple calculator web app built with Java Servlet and JSP.

## Run in IntelliJ IDEA
1. Open the folder in IntelliJ IDEA.
2. Let IntelliJ detect the Maven project.
3. Add a Tomcat or Jetty run configuration.
4. Deploy the project and run it.
5. Open the browser at http://localhost:8080/calculator/.

## Build
Run:
```bash
mvn package
```
